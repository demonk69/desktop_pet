# Roadmap

## V0.1 软件骨架

- 模块边界、状态机、事件、动画、HAL、配置
- 无硬件测试
- 依赖最少的 PC framebuffer demo
- 硬件未知项和 Bring-up 文档

退出条件：工程可编译，基础测试通过，模拟器复用正式 Pet Core。

## V0.2 PC 模拟桌宠

- 交互式窗口和键盘事件
- 资源 provider 和基础素材流水线
- UI 布局扩展点、时间驱动与更多行为测试

## V0.3 LCD Bring-up

- 确认 MCU/SDK/引脚
- SPI 或 8080 backend
- ST7789 初始化、纯色、方向、色序和区域刷新验证
- PWM 背光

## V0.4 真机动画

- 资源放置策略
- PSRAM/DMA/framebuffer 性能验证
- 真机动画帧率、撕裂和功耗优化

## V0.5 Wi-Fi / 时间

- Wi-Fi service
- 网络状态事件
- 时间同步和基础时间显示

## V0.6 PC 通信

- 传输协议和版本协商
- 调试、资源或消息通道

## V0.7 AI

- AI service 接口和异步消息流
- 对话状态、错误处理和隐私策略

## V1.0 第一版完整桌宠

- 稳定硬件显示和交互
- 核心在线服务
- 可恢复错误、功耗和发布流程
